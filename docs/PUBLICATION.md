# Publication scope

This is a public review copy, not a complete production-server backup.

Included: verified release source snapshots and supplied audio, current controller
source/tests, portal feature iterations, monitoring compatibility code, deployment
helpers, service templates, and implementation notes. Existing third-party dependencies
are referenced rather than vendored.

Excluded: compiled firmware, raw release tarballs, private configuration and backups,
credentials, production database/visitor records, admin preview HTML/screenshots,
personal setup logs, synced proposal/reference documents, and duplicated working copies.
These remain privately stored.

Historical source was verified against each original archive manifest before import.
Private identifiers were replaced consistently. Source dates use recorded release
build times, not unverified filesystem creation times. Supplementary portal files
and tests are committed at import time because equivalent historical release evidence
is unavailable. This avoids inventing development dates.
