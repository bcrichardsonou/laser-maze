# Imported development history

This repository was assembled from existing local ZoCo Laser Maze release archives.
These are reconstructed release snapshots, not evidence of earlier GitHub publication.
Author dates preserve each archive manifest’s `created_at` (release-build time). They do
not establish the first creation date of each individual file. Git committer dates record
the actual import. Unknown earlier edits have not been invented.

Private runtime configuration, credentials, deployment binaries, raw production records,
and copied personal/hosting identifiers are excluded or replaced with examples. The
original private archives remain unchanged. Public snapshots may therefore have different
file checksums; source archive checksums and original source-file checksums are documented.
